# Final Integrated MiniBank

This is the complete MiniBank application integrated through Practical 14. It includes the supporting Java classes, persistence/reporting utilities, data/log folders, tests, Maven configuration, and run/build scripts.

- `run.bat` runs the console application.
- `build-jar.bat` builds the runnable JAR when Maven is installed.
- `src/main/java` contains application source; `src/test/java` contains JUnit tests.

The `Practical-01` to `Practical-13` folders in the parent archive contain only files introduced or modified for that practical. They are incremental submission folders and may need earlier practical classes to compile.
